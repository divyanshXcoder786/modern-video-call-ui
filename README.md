🎥 Modern Video Call UI

A sleek and modern **video calling user interface** built using HTML, CSS, and JavaScript.  
This project focuses on creating a beautiful, responsive, and interactive UI for real-time video communication.


💡 About the Project

This project is a frontend-only video call UI designed to simulate a real video calling experience.  
It can be extended later with WebRTC or backend integration for real-time video communication.


✨ Features

🎥 Clean video call layout (caller & receiver UI)  
🟢 Online/active status indicator  
🎙️ Mic on/off button UI  
📷 Camera on/off toggle UI  
💬 Chat panel (UI ready)  
📞 Call / End call buttons  
🌙 Modern dark-themed interface  
📱 Fully responsive design  


🛠️ Tech Stack

- 🌐 HTML5  
- 🎨 CSS3 (Flexbox + Grid + Animations)  
- ⚙️ JavaScript (UI interactions)

1. Download or clone the project  
2. Open `index.html` in your browser  
**OR**
